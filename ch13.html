1派一个探路员
地形
在地图上按住拖动白点换起点。“考场”把整片地形沿 $(1,1)$ 方向平移 $\delta$：考场损失 $=\mathcal L(\mathbf w-\delta(1,1))$，模拟期末题目和练习题“考的是同一个公式，但数字变了一点”。
⛰GD 与 SAM 的路线
普通梯度下降SAM探路一步 $\hat{\boldsymbol\epsilon}=\rho\,\mathbf g/\|\mathbf g\|$谷底线（红尖 → 绿平）
①②SAM 一步拆解（在起点处）
∪书中两条抛物线：宽盆地 $w^2$ 与窄深井 $10000w^2$
∑背后的公式
$$\begin{gathered}\min_{\mathbf{w}} \max_{\|\boldsymbol{\epsilon}\|_2 \le \rho} \mathcal{L}(\mathbf{w} + \boldsymbol{\epsilon}),\qquad \hat{\boldsymbol{\epsilon}}_t = \rho \frac{\nabla \mathcal{L}(\mathbf{w}_t)}{\|\nabla \mathcal{L}(\mathbf{w}_t)\|_2},\qquad \mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla \mathcal{L}(\mathbf{w}_t+\hat{\boldsymbol\epsilon}_t) \\ \nabla \mathcal{L}(\mathbf{w}_t+\hat{\boldsymbol\epsilon}_t) \approx \nabla \mathcal{L}(\mathbf{w}_t) + \rho\,\mathbf{H}(\mathbf{w}_t)\frac{\nabla \mathcal{L}(\mathbf{w}_t)}{\|\nabla \mathcal{L}(\mathbf{w}_t)\|_2},\qquad \mathcal L(\mathbf w^*+\boldsymbol\delta)\approx\mathcal L(\mathbf w^*)+\tfrac12\boldsymbol\delta^\top\mathbf H\boldsymbol\delta\end{gathered}$$

谷底处一阶导数为 0，考场偏移 $\boldsymbol\delta$ 带来的罚分完全由二阶导数 $\mathbf H$ 决定。SAM 在高处测的斜率里自动多出 $\rho\mathbf H\hat{\mathbf g}$ 这一项：越尖的地方被推得越狠，所以它站不住窄深井。“一谷多底”地形 $\tfrac12(w_1w_2-1)^2$ 的谷底是整条双曲线 $w_1w_2=1$，训练损失处处为 0，但曲率 $\lambda_{\max}=w_1^2+w_2^2$ 在两端很大、在 $(1,1)$ 处最小。

🧪 试一试

  1. 默认从 $(3.6,\,0.15)$ 出发：GD 一头扎进离自己最近的谷底 $(3.6,\,0.28)$，曲率约 13；SAM 先落到谷底，再沿着谷底线一路滑向 $(1,1)$，曲率降到 2 左右。两者训练损失都几乎是 0，考场损失 SAM 低好几倍。
  2. 把 $\rho$ 调到 0：SAM 退化成普通 GD，两条路线重合。$\rho$ 越大，滑向平坦处越快。
  3. 切到“书中椭圆碗”：起点 $(1.0,\,0.1)$、$\rho=0.1$、$\eta=0.015$，拆解卡片里就是书中手算的 $\mathbf g_0=(1,10)$、$\hat{\boldsymbol\epsilon}\approx(0.010,0.0995)$、$\mathbf g_{\text{adv}}\approx(1.010,19.95)$：陡方向的斜率几乎翻倍，缓方向只涨 1%。
  4. 看两条抛物线：考场偏移 0.1 时，宽盆地罚 0.01，窄深井罚 100；探路员走出 0.1 后，测到的斜率一个是 0.202，一个是 2020。
2学做“模 11 加法”
玩具模型 = 两条“电路”相加：查表电路给每道题一个固定的随机特征 $\boldsymbol\phi(a,b)\in\mathbb R^{64}$，再乘一张可训练的大表 $\mathbf W$，能把练习题全部背下来，但对没见过的题只会瞎猜；规律电路直接给正确答案 $(a+b)\bmod 11$ 加分 $0.5\,uv$，$u,v$ 从 $10^{-3}$ 起步，所以一开始几乎没有斜率、学得很慢。全批量梯度下降 + 解耦权重衰减 $\mathbf w\leftarrow(1-\eta\lambda)\mathbf w-\eta\nabla\mathcal L$，共 16384 步。这里的步数是玩具模型的；论文里的模运算实验不到 $10^3$ 步就背熟，开窍要等到 $10^5$～$10^6$ 步。
✓练习题与考题的正确率横轴对数刻度
练习题（训练集）考题（没见过的题）瞎猜水平 1/11
‖w‖²两条电路各占多少“旋钮租金”
查表电路 $\|\mathbf W\|_F^2$规律电路 $u^2+v^2$总和
λ不同权重衰减下的考题正确率
∑背后的公式
$$\begin{aligned}&\mathbf{w}_{t+1} = (1 - \eta \lambda)\mathbf{w}_t - \eta \nabla \mathcal{L}_{\text{train}}(\mathbf{w}_t),\qquad \Delta T_{\text{grok}} \approx \frac{1}{\eta\lambda}\ln\!\left(\frac{R_{\text{mem}}}{R_{\text{grok}}}\right)\\ &\text{租旋钮费：}\ \tfrac{\lambda}{2}\|\mathbf w_{\text{mem}}\|^2=\tfrac{0.01}{2}\times1000=5.00,\qquad \tfrac{\lambda}{2}\|\mathbf w_{\text{grok}}\|^2=\tfrac{0.01}{2}\times10=0.05\end{aligned}$$

书中的例子：$\eta=0.001$、$\lambda=0.25$，$R_{\text{mem}}/R_{\text{grok}}=20/2$，$\Delta T\approx\ln10/0.00025\approx9200$ 步。背完题之后练习题的罚分已经是 0，只剩权重衰减每步把旋钮捏小 $(1-\eta\lambda)$ 倍；查表电路越缩越背不住，规律电路用小得多的旋钮就能做对所有题，于是慢慢接管。

🧪 试一试

  1. 默认 $\lambda=0.03$：几十步内练习题就 100% 正确，考题却在 9% 左右（瞎猜）徘徊很久；一千多步后考题正确率突然冲到 100%，这就是“顿悟”。
  2. 看旋钮租金图：背书阶段查表电路的 $\|\mathbf W\|^2$ 先涨上去；顿悟时它被压下来，规律电路接管，总租金变小。
  3. 把 $\lambda$ 调到 0 再训练：在这个玩具模型里，16384 步内考题一直是瞎猜水平，查表电路的旋钮越背越大，没有任何力量逼它换路。真实实验没这么绝对：Power 等人论文图 1 那组用的就是不带权重衰减的 Adam，也开窍了，只是要等到 $10^5$～$10^6$ 步；权重衰减能让顿悟来得早得多。
  4. 点“对比 4 种 $\lambda$”：权重衰减越大，顿悟来得越早，和 $\Delta T\propto1/(\eta\lambda)$ 的趋势一致。

∑背后的公式
$$\frac{f(a) + f(b)}{2} - f\Big(\frac{a+b}{2}\Big) = \frac{(a-b)^2}{4} \ge 0\quad(f(x)=x^2)$$
$$\mathbf{w}_{\text{TIES}} = \mathbf{w}_{\text{pre}} + \alpha\,\boldsymbol{\tau}_{\text{TIES}},\qquad \tau_{\text{TIES}, i} = \frac{1}{|\mathcal{A}_i|}\sum_{m \in \mathcal{A}_i} \hat{\tau}_{m, i},\qquad \mathcal{A}_i = \Big\{m : \hat{\tau}_{m,i} \ne 0,\ \operatorname{sign}(\hat{\tau}_{m,i}) = \operatorname{sign}\Big(\sum_{k} \hat{\tau}_{k,i}\Big)\Big\}$$

只要两个模型在同一个碗里，取平均一定不比两端的平均差，而且省下的罚分正好是距离平方的四分之一。如果中间隔着一座山，平均反而会掉进山脊。TIES 先把每个专家改动最小的那部分修剪成 0，再按总和投票选出每个旋钮的方向，最后只对“赞成派”求平均，避免被唱反调的专家和不相干的 0 稀释。

🧪 试一试

  1. 默认是书中的 $\mathbf w_A=(-0.2,\,0.4)$、$\mathbf w_B=(0.4,\,-0.2)$：两端罚分都是 0.20，中点 $(0.1,0.1)$ 只有 0.02，正好省下 $0.09+0.09=0.18$。
  2. 切到“两个碗之间隔着山”：A、B 各在一个碗底，连线中点正好落在山脊上，平均后的罚分比两端都高。合并的前提是“同一个盆地”。
  3. TIES 默认是书中正文的例子：第 1 号旋钮简单平均只有 $+0.267$，TIES 剔除唱反调的 $-0.2$ 后是 $+0.50$；四个旋钮依次是 $(0.50,-0.50,-0.40,0.30)$。
  4. 切到“零算力实战版”（把两个 0 换成 0.01、0.02，并修剪每个专家最小的 25%）：结果和正文版一样。再把修剪比例调到 0：第 4 号旋钮的 0.02 混进平均，结果从 0.30 被稀释到约 0.21（第 3 号旋钮的 0.01 方向不对，投票时已被排除）。
