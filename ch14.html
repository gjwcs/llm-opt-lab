∑背后的公式
$$\begin{gathered}\mathcal{L}_{\text{total}} = \underbrace{-z_y + \ln Z}_{\text{交叉熵}} + \underbrace{\alpha (\ln Z)^2}_{\text{Z-Loss}},\qquad \ln Z = \ln\sum_{j} e^{z_j} \\ \frac{\partial \mathcal{L}_{\text{total}}}{\partial z_i} = \big(p_i - \mathbb{I}(i=y)\big) + 2\alpha (\ln Z)\, p_i,\qquad \sum_i\frac{\partial \mathcal{L}_{\text{total}}}{\partial z_i}=2\alpha\ln Z\end{gathered}$$
$$\tilde{\mathbf{g}}_t = \min\!\Big(1, \frac{c}{\|\mathbf{g}_t\|_2}\Big) \mathbf{g}_t$$

交叉熵对所有打分的导数加起来恰好是 0，所以它看不见“所有打分一起涨”；Z-Loss 的导数总和是 $2\alpha\ln Z$，$\ln Z$ 一离开 0 就被往回拉。书中算例：$z=(1000,1002)$ 时 $\ln Z=1000+\ln(1+e^2)\approx1002.13$，拉回到 $(-2.13,\,-0.13)$ 后 $\ln Z=0$，两者之差仍是 2，预测概率一点没变。梯度裁剪只缩短步子、不改方向。

8 个词，查询与键向量 $\mathbf q_i=s\,\tilde{\mathbf q}_i$、$\mathbf k_j=s\,\tilde{\mathbf k}_j$，$\tilde{\mathbf q},\tilde{\mathbf k}$ 的每个坐标都是标准正态。$s$ 模拟训练后期 $\mathbf W_Q,\mathbf W_K$ 的刻度一起涨了 $s$ 倍。

不加 QK-Norm：$\propto s^2$QK-Norm：不超过 $\bar\gamma^2\sqrt{d_k}$FP16 下 $e^{s}$ 溢出线 11.09FP32 溢出线 88.7
∑背后的公式
$$\hat{\mathbf{q}}_i = \gamma_Q \odot \frac{\mathbf{q}_i}{\sqrt{\frac{1}{d_k}\|\mathbf{q}_i\|_2^2 + \epsilon}},\qquad \hat{\mathbf{k}}_j = \gamma_K \odot \frac{\mathbf{k}_j}{\sqrt{\frac{1}{d_k}\|\mathbf{k}_j\|_2^2 + \epsilon}},\qquad s_{ij}^{\text{QK-Norm}} = \frac{\hat{\mathbf{q}}_i^\top \hat{\mathbf{k}}_j}{\sqrt{d_k}} \approx \bar{\gamma}^2 \sqrt{d_k}\, \cos\angle(\mathbf{q}_i, \mathbf{k}_j)$$

不加 QK-Norm 时 $s_{ij}=\mathbf q_i^\top\mathbf k_j/\sqrt{d_k}$，$\mathbf W_Q$、$\mathbf W_K$ 各涨 $s$ 倍，打分就涨 $s^2$ 倍：Softmax 先是变成“只看一个词”的独热分布（梯度几乎为 0），再往后就是 $e^{s_{ij}}$ 溢出。QK-Norm 在相乘前把两个向量各自缩回均方根为 1，打分只剩夹角余弦，被锁在 $[-\bar\gamma^2\sqrt{d_k},\,\bar\gamma^2\sqrt{d_k}]$ 里。

  1. 点“书中例子”：$\mathbf q=\mathbf k=(20,20,20,20)$，不加 QK-Norm 时 $s_{ij}=1600/2=800$，$e^{800}$ 直接爆表；加上 QK-Norm 后两个向量都变成 $(1,1,1,1)$，打分只有 $4/2=2.0$，$e^{2}\approx7.389$。
  2. 把刻度 $s$ 从 1 慢慢拖大：左边热力图的每一行越来越像“只亮一格”，平均熵跌向 0；右边 QK-Norm 的热力图完全不变。
  3. 看曲线：未归一化的最大打分沿 $s^2$ 直线上涨，先后穿过 FP16 与 FP32 的溢出线；QK-Norm 是一条水平线。
  4. 把 $\gamma$ 调大：QK-Norm 的天花板 $\bar\gamma^2\sqrt{d_k}$ 跟着抬高，这就是“可学习的温和缩放旋钮”。

理想（无限精度）四舍五入随机舍入：平均随机舍入：单次抽签
√T走得越久，误差怎么长？双对数坐标
四舍五入：每步都赖掉 $\delta$，误差 $\propto T$随机舍入：误差均方根 $\approx\Delta\sqrt{T\,p(1-p)}\propto\sqrt T$
∑背后的公式
$$\operatorname{SR}_\Delta(x) = \begin{cases} \lfloor x \rfloor_\Delta + \Delta, & \text{概率 } p = \dfrac{x - \lfloor x \rfloor_\Delta}{\Delta} \\[6pt] \lfloor x \rfloor_\Delta, & \text{概率 } 1 - p \end{cases}\qquad \mathbb{E}\big[\operatorname{SR}_\Delta(x)\big] = x,\qquad \operatorname{Var}\big(\operatorname{SR}_\Delta(x)\big) = \Delta^2 p(1-p) \le \frac{\Delta^2}{4}$$

四舍五入每一步都往同一个方向赖账，$T$ 步就少走 $T\delta$；随机舍入每一步的误差平均为 0、互不相关，加起来只按 $\sqrt T$ 增长。真实的浮点数刻度不是等距的：BF16 只有 7 位尾数，在 1.0 附近相邻两个数差 $2^{-7}\approx0.0078$；FP8 只有 2～3 位尾数：E4M3 有 3 位，差 $2^{-3}=0.125$（E5M2 只有 2 位，差 0.25）。

🧪 试一试

  1. 默认是书中的例子：刻度 0.1，从 1.0 出发每步 $+0.01$ 走 100 步。四舍五入死死卡在 1.0；随机舍入每次有 10% 的机会进一格，平均正好走到 2.0；单次抽签会在 2.0 上下晃（标准差约 0.3，书中脚本打印的那一次停在 1.9）。
  2. 把步数拉到 10000：四舍五入的误差变成 100；随机舍入的误差只有约 3（$0.1\times\sqrt{10000\times0.1\times0.9}$）。
  3. 切到 BF16，每步 $+0.001$：0.001 不到 1.0 附近刻度 0.0078 的一半，四舍五入同样一步都走不动。这就是为什么混合精度训练要保留一份 FP32 主权重，或者改用随机舍入。
  4. 把每步改动调到大于半格（例如刻度 0.1 时调到 0.06）：四舍五入会走，但每步都多走 0.04，照样越走越偏。
